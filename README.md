# Mankiewicz Favorite Spots – Images

Dieses Repository ist für öffentlich erreichbare Bilddateien vorgesehen, die später über eine direkte Raw-URL in Google My Maps verwendet werden können.

## Struktur

```text
mankiewicz-favorite-spots-images/
└─ submissions/
   ├─ spot-0001-01.jpg
   ├─ spot-0001-02.jpg
   └─ spot-0002-01.jpg
```

Empfohlenes Namensschema:
`<spot-id>-<laufende-nummer>.<endung>`

Beispiel:
`spot-0001-01.jpg`

Direkte Raw-URL:
`https://raw.githubusercontent.com/OWNER/mankiewicz-favorite-spots-images/main/submissions/spot-0001-01.jpg`

Wichtig: Wenn das Repository öffentlich ist, sind auch die darin gespeicherten Bilder öffentlich erreichbar.
